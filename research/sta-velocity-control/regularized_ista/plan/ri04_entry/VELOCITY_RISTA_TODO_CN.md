## 2. 数学与接口约定（RI00 必须再逐式审计）

来源包误差为 `e=v_sp−v`；本研究沿用 `s=v−v_sp`。nu 仍是加速度纠偏状态，不因误差符号更换而擅自反号。定义 `rho(x)=sat(x/epsilon)`、`Psi(x)=sqrt(max(abs(x),epsilon))*rho(x)`。

在恒定目标、无 FF/限幅的名义候选模型中，按本分支符号转换后的关系为：

```text
p              = s[k] + h * (a_ideal[k] - nu[k])
nu_candidate   = nu[k] - h * lambda2 * rho(p)
a_ideal[k]     = -lambda1 * Psi(p) + nu_candidate

即：p + h*lambda1*Psi(p) + h^2*lambda2*rho(p) = s[k]
```

`p` 是补偿后的名义预测误差，不是下一时刻测得的真实误差；nu 不是瞬时准确的扰动观测器。输出含 **nu_candidate**，不同于 R-STA 用旧 nu 的当前输出。候选与最终提交状态必须分别记录。

供审计的分段消元形式：设 `A=h*lambda1`、`B=h^2*lambda2`、`b=epsilon+A*sqrt(epsilon)+B`。

```text
|s| <= b：p = s / (1 + A/sqrt(epsilon) + B/epsilon)
|s| >  b：C=|s|-B
          r=2*C/(sqrt(A*A+4*C)+A)
          p=sign(s)*r*r
```

有理化仅避免相近数相减；`A*A`、`4*C`、`2*C`、分母、平方和尺度仍可能上溢/下溢，需测试或进一步等价缩放，不能把此式称全浮点域安全。用独立单调隐式求根/残差核对，不能复制同一解析式当唯一参考。

| 量 | 单位/约定 |
|---|---|
| s、p、epsilon | m/s，本地 NED；X 北、Y 东、Z 下，上升 vz<0 |
| a_ideal、nu、a_ff | m/s²；核只输出速度加速度纠偏 |
| lambda1 | (m/s²)/sqrt(m/s) |
| lambda2 | m/s³ |
| h | s，真实 sample 更新间隔；不是固定 .005 s |

R03 速度更新约 100 Hz，典型 sample 间隔 8/12 ms；来源模型为 5 ms。冻结实际旧日志样本供回放，验证固定周期与变周期，不能用 PID 旧 clamp dt 隐藏新核异常。

纯核不含 FF、质量、rate 输入增益 g、重力/PWM 或推力平方律；适配层保持纠偏限幅后加一次原有效 FF，再走既有推力/倾角/Z 优先映射。不无条件增加来源包装中的 `-lambda*velocity`，也不复制模型的总加速度/油门限制。
