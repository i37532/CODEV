# Proper-ISTA 速度对象离线对比协议

日期：2026-10-24。用户授权按上轮建议先离线比较，不接执行器、不飞行、不改变默认参数。入口 `research/ista-velocity-regularized` / `8ff776664b63bef1c630db8c625f095a028cfb6b`，工作区干净。此项是独立研究探针，不是 RI05、速度 Proper 模式或新的飞行验收；原 RI04 和所有冻结包保持原样。

## 算法与问题

仅比较未修改的 R-STA、R-ISTA 与 Proper-ISTA 数学核。前两者取当前 Z 共同候选 λ1=2、λ2=1、ε=.02；Proper 取相同 λ1/λ2，**没有 ε**。不采用上一轮增益对齐候选，不搜索参数，不要求任何算法获胜。比较包含控制律与正则化差异，不称纯 Euler 离散方式消融或公平调参后的最终性能。

Proper 复用 `ProperIstaRateControl` 的纯数学实现，仅在研究目录桥接，以 `g=1` 恒等输出解释为速度纠偏。s=v−v_sp（m/s），a/ν为m/s²，λ2为m/s³；不是调用角速度模块，也不宣称真实飞机通道增益为1。没有增加质量、重力或重复 FF；未注册任何速度模式。

固定文献为 [Proper Implicit v1](https://arxiv.org/html/2406.16094v1)，公式(11a)/(12)/(13)。

```text
z = s + h*(a - nu_next)
a = -lambda1*sqrt(abs(z))*xi + 2*nu_next - nu_old
nu_next = nu_old - h*lambda2*xi, xi in Sgn(z)
```

独立 binary64 参考对 `z+h*λ1*sqrt(|z|)*xi+h²*λ2*xi=s` 单调求解，并从预测方程恢复 a；不用生产的有理化解析根。检查三式和包含关系。候选必须独立提交，物理对象不能用虚拟 z 代替。

## 预定矩阵

三算法 × 四周期 × 十二场景 = **144 条**，每条36秒，最多全部执行一次；工具/测试错误修复可以重跑，但保留所有尝试，不把重复轨迹算独立样本。

周期：固定8、10、12ms及交替8/12ms。36秒均整除，无末拍缩短。交替序列代表日志已观察到的周期结构，不冒充逐条旧ULog原序回放。对象按精确标称间隔积分，核接收对应float h，数值差异单列。共同初值 v=.03m/s、ν=.1m/s²；负扰动场景镜像；零扰动保留非零初始状态。

## 指标与正确性

- 同时保留全0–36s与固定12–36s窗口，不看结果选窗口。按真实更新间隔加权，报告真实速度与测量速度RMSE、均值、峰值；纠偏TV/s按更新序列相邻差计算，另报告峰值输出/ν、限幅比例与数值拒绝。TV不是能耗。
- 每个实际 C++ 步与同一舍入输入的独立参考比对，输出/状态缩放差≤2e−6；另跑完全独立double闭环并报告物理轨迹差。参考不是抄录 C++ 输出。
- 固定周期斜坡的 Proper 理论值 `r*h²`、R-STA层内值 `r*ε/λ2`、R-ISTA层内值 `r*(ε+hλ1√ε+h²λ2)/λ2`：独立double尾窗偏差≤1e−11m/s，float尾窗另列，Proper float偏差≤5e−7m/s。r=.1的理论量级6.4e−6至1.44e−5可区别于float误差，不用宽容差掩盖h²关系。只有固定周期/理想/无约束场景使用该判据；零/恒扰数值终点与非零尾误差如实保存。
- 数值拒绝不补零、不假称完成36s；保留停止时输入与状态、已完成秒数、状态码。它是诊断结果，不能用“模型检查通过”冒充所有轨迹收敛。
- 不可行限幅反例应实际裁剪且终端速度误差超过2m/s；这是控制能力不足，不是算法实现通过的反面，也不删去。
- 测试精确±h²λ2边界及float邻点（用可精确表示h=1/128）、一般8/12ms、正负/零/非零ν、无效时间/参数/测量、三轴隔离、reset及陈旧/重复候选。旧PID和相关内核非零回归；三个实际数学核重新严格C++14编译。
