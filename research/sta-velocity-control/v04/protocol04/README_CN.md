## 最小修订

1. 解锁前保存原地面 xyz、原 yaw、全局参考和所有 reset 计数，后续不重置参考。
2. 仅在首次起飞准备段、尚未发高度任务时，允许至多一次有证据的初次空中磁航向对齐：相同健康主估计器，`mag_aligned_in_flight` 从 0 到 1，航向/四元数计数各增加一次，修正量一致；无位置/速度 reset、参考变化、切换或故障。高度范围 1–3m、航向修正绝对值不超过 5°，不是“任何小 reset 都允许”。
3. 异步对齐证据最多等待 0.5s，期间不得进入高度任务。周期 estimator_status、约 1Hz 的 selector/status_flags、仅事件发布的 event_flags 分别检查，不能用同一过期阈值误杀，也不能缺字段当正常。
4. 对齐确认后，在 POSCTL 连续稳定至少 1s，现有 yaw 目标新鲜且与估计相差不超过 1°，才一次性固定对齐后的任务 yaw。该新值不再加 `delta_heading`，不改变地面位置/高度参考。它替代旧协议“解锁前固定任务 yaw”，须披露这一任务定义变化。
5. 固定后通过降落上锁，任何新航向 reset 仍失败。位置/速度 reset、主估计器切换和全局参考变化全程拒绝；旧基线出现过的降落切换不在例外内。
6. 原准备总超时 150s、2.5m 高度目标、入口与观察/激励窗口、PID/ESTA 参数和配对门槛不变。所有失败停止、保留，不补飞。

新准入值基于开发日志与既有 20° yaw 边界制定，是工程检查，不是理论保证或独立留出结果。私有 EKF 判据使用延迟内部地形高度，不能把导出的无效测距字段当作精确复现。
