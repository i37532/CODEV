## 2. 实现了什么

| MODE / AXES | 正常 ESTA 轴 | 正常剩余速度 PID 轴 | 实际路径 |
|---|---|---|---|
| 0 / 0 | 无 | XYZ | 原 PID |
| 1 / 1 | X | YZ | 原 X 路径 |
| 1 / 2 | Y | XZ | 新 Mixed 路径 |
| 1 / 3 | XY | Z | 原 XY 路径 |
| 1 / 4 | Z | XY | 原 Z 路径 |
| 1 / 5 | XZ | Y | 新 Mixed 路径 |
| 1 / 6 | YZ | X | 新 Mixed 路径 |
| 1 / 7 | XYZ | 无 | 原 XYZ 路径 |

表格限三轴速度目标合法、正常空中、已交接。NED X/Y/Z 为北/东/下，不是 roll/pitch/yaw。

1. **真实模块与准入**：Run 先验证原 signed AXES 再窄化；无效/禁用组装 0，不再默认组装 X。selector 保留原 signed requested/effective/pending/reject，MODE2、越界、MODE0非零掩码拒绝。有效配置仅在 disarm 且 MODE/AXES 全事务通过后更新，拒绝请求不会污染旧有效增益。
2. **新混合控制**：`_velocityControlEstaMixed` 仅处理 2/5/6；正常只计算选中 ESTA，未选中轴继续原 P/I/D 与 ARW。先合成纠偏和一次原 FF，再经过原倾角、Z优先/XY余量映射，保护层验证整组选轴后原子提交 ν；不把 PID `2/Kp` ARW 用于 ν。
3. **Z 交接**：XZ/YZ 地面/ramp/contact 保持完整原 PID；priming 一帧输出 PID，所有活动 ESTA 轴的 seed/ν/纠偏/完整推力映射均有效且无裁剪才整体播种。下一样本开始 ESTA；未选水平 PID 状态连续。活动速度轴变化重新交接，加速度-only 部分不偷偷恢复 PID。
4. **HTE**：已有 bit4 入口接通 XZ/YZ 的 `shiftZ`；有限性/饱和/限值不合格仍 latch。水平 ν 不继承 Z 补偿，未改变 PID 的 HTE 算法。
5. **时间与故障**：保留原 PID dt、ESTA sample 差及 2–40ms 门槛、重复样本拒绝和 disarm 清 latch。同帧 failsafe 重算不二次提交。新路径先检查原始 XY 成对目标，避免位置限幅转换后才发现非法输入而已重置/播种部分状态。
6. **分频及默认**：专项脚本固定 DIV1；新2/5/6只允许 DIV1，含Z原4/7仍DIV1。旧 PID/X/XY DIV2/4回归保留。默认 MODE0/AXES0/DIV1，默认 ESTA 增益和限值仍0；非SITL准入宏仍关闭（本次未构建实机）。
7. **日志与脚本**：修正 MODE/AXES 元数据及消息旧注释，字段布局不改。新离线 [interface.py](../axis_ablation/ax01/interface.py) 支持八名称、未知名拒绝；输出统一候选参数，不连接飞控。解析真实模块同步测试轨迹，检查模式/轴/提交/PID/交接/ν/双时钟/序号。完整飞行运行器及 ULog 新矩阵验收仍属 AX02，旧运行器和旧分析器不就地改义。

`a_sta` 为 m/s² 纠偏，`a_req` 为加一次 FF 后需求，`thrust` 为归一化推力，`a_proxy` 为推力映射代理、不是实测加速度。ν 每轴独立，理想候选和受保护应用状态仍分列；逻辑原子性不是多线程同步保证。
