# R01 独立数值与对象验证协议 v1（运行前冻结）

2026-10-16。范围：实际新 C++ float 核与独立 binary64 参考/对象；0 飞行、0 MATLAB。
不调整增益、不搜索 epsilon；唯一候选 X/Y=.01、Z=.02 m/s，R00 的12个解析筛查点另记。
旧增益 X/Y=.5/.1、Z=2/1，nu 限制 .4/4、纠偏限制 .8/6。只定义水平/垂直两类标量对象，
不把X与Y复制样本计作独立动力学证据；三轴隔离由内核单测覆盖。

## 固定离线矩阵

2算法（实际旧ESTA/新R-STA）×2增益类×4时间序列×10对象条件 = **160 条30秒轨迹**。
时间：固定8、10、12ms，以及读取R00已审计AX05 run007主窗的实际sample间隔；
最后一步沿固定序列推进至首次达到30s，最多多一个周期，不裁短步长。
真实序列只用旧、已公开的开发知识，不读取新正式留出；核对原ULog SHA。

固定10条件：

1. 零扰动，初始速度误差 .08，nu0=.05；
2. 恒定 +.08 m/s²，nu0=-.05；
3. 恒定 -.08 m/s²，nu0=.05；
4. 斜坡 d=.02+.002*t，nu0=0；
5. 斜坡 d=-.02-.002*t，nu0=0；
6. 目标 v_sp=.12*sin(2*pi*t/8)，一次FF为其解析导数，d=.04；
7. 测量噪声 .002*sin(2*pi*23*t)+.001*sin(2*pi*37*t)，d=.04；
8. 姿态/电机两级一阶滞后 tau=.04/.025s，d=.04；
9. 控制能力不足反例：d=1.2、下游总加速度限幅±.2，nu0=0；
10. 第6的变化目标+FF、第7噪声、第8滞后同时存在，d=.04。

除第9外初始速度 .08；第9初始0。未另指明nu0为0。每一步用旧nu计算输出，再提交一次。
对象位置/速度、两级滞后在Python中以独立解析ZOH积分；斜坡扰动采用区间精确平均。
每条同时运行实际float控制器驱动对象和独立double控制器驱动的另一对象。
同输入局部参考以实际float可表示输入、参数、旧nu为起点；独立double闭环不强制共享实际float轨迹。

## 参考、保护代理与预定判据

- 参考使用包内乘积式 `sqrt(max(abs(s),epsilon))*clip(s/epsilon)`，不是复制新核分段代码。
  只产生纠偏；夹限纠偏后加一次FF，必要下游限幅；nu按残差方向条件冻结并限制幅值。
  这是研究对象的标量保护代理，不冒称生产三轴公共保护/HTE/起降验证。
- 各有效样本对照局部参考：a_sta、nu_candidate、s 的缩放绝对误差 ≤ **2e-6*(1+|reference|)**。
- 新R-STA独立double闭环最大速度差 ≤ **2e-4 m/s**；旧硬sign长时相位差不作逐点等价门槛，
  只报告差异且所有局部参考仍必须通过。
- 所有轨迹有限；|velocity|<50 m/s、|nu|不超规定限制，FF必须精确只加一次。
  这些是离线模型健全性界，不是飞行安全阈值。
- 新R-STA理想零/恒定扰动最后5s真实误差RMSE ≤ **5e-4 m/s**；
  斜坡尾窗均值与 `epsilon*r/lambda2` 差 ≤ **5e-4 m/s**。
- 第9必须识别控制能力不足，末速度>20 m/s、存在输出限制；其“检查通过”不代表控制成功。
- 对变化目标、噪声、滞后报告真实误差与测量误差、均值/方差、纠偏TV/T、峰值和限制比例；
  不要求新算法优于旧ESTA，不以胜负改参数、任务、容差或删除失败。

另固定一步输入网格：2增益类×4 epsilon(.001,.01,.02,1)×正负层内/边界/float邻点/层外/零
×3初始nu×4周期(.002,.008,.012,.04)×2目标偏置(0,.375)，共 **2112 组**。
采用实际float输入值再做double比较，显式保留输入表示误差，不把它误判成C++公式错误。
