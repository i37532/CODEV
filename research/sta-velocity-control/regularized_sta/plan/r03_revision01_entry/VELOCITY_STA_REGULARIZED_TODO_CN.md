## 2. 数学与接口约定

包内误差为 e=v_sp−v；PX4 沿用 s=v−v_sp，不能只复制符号。

对选中轴 i，定义：

~~~text
rho(s, epsilon) = sat(s / epsilon), sat 限于 [-1, 1]
Psi(s, epsilon) = sqrt(max(abs(s), epsilon)) * rho(s, epsilon)

a_sta[k]       = -lambda1 * Psi(s[k], epsilon) + nu[k]
nu_candidate   = nu[k] - h * lambda2 * rho(s[k], epsilon)
~~~

当 |s|≤epsilon，Psi=s/sqrt(epsilon)；层外 Psi=sqrt(|s|)sign(s)。旧 nu 计算当前输出，保护裁决后最多提交一次新 nu；evaluate 不修改状态。

| 量 | 单位与含义 |
|---|---|
| s、epsilon | m/s，epsilon 是速度误差边界层宽度 |
| a_sta、nu | m/s²，速度反馈纠偏/积分状态 |
| lambda1 | (m/s²)/sqrt(m/s)，即 √m/s^(3/2) |
| lambda2 | m/s³ |
| h | s，算法真实更新间隔 |
| a_ff | m/s²，PX4 原有效加速度前馈 |

epsilon 必须有限且严格为正，数值上下界在 R00/R01 根据推导与测试固定；epsilon=0 不得隐式切回旧 ESTA。新参数变更必须进入配置代次和候选失效规则。

首轮保持当前 PX4 顺序：纠偏限幅 → 加一次有效 FF → 原加速度/推力映射及耦合限制。分别记录理想候选、受保护应用量和最终发布量；推力映射代理不是实测加速度。

禁止直接移植：
- 包内用于特定恒定位置目标的 −lambda*v 前馈；这里 lambda 是外位置增益，不是 lambda1。
- 质量/PWM/电机平方律、固定悬停油门；速度输出不使用 rate 的 g，也不重复除质量。
- 包内 FF+纠偏后的总量裁剪，以及 Z 的 [-22,+8] 总加速度界；它们不等同当前纠偏限幅参数。
- 包内仅凭 nu 数值相等判断候选是否可提交的弱检查；保留 owner/axis/revision/payload 等事务校验。

