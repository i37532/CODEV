## 2. 固定公式与状态接口

沿用 I00 固定 [arXiv:2406.16094v1 PDF](https://arxiv.org/pdf/2406.16094v1)，
SHA-256 `9aa4a20ef2a0f562cfad897e18cb8db96cf174fd332592bb2887e19ddafdd73b`。
实现无执行器饱和版本，PDF (11a)/(12)/(13)，Theorem 3.1/3.4；不是其 conditioned 变体。

```text
s = rate - rate_sp
z = s + h*(a - nu_next)
a = -lambda1*sqrt(|z|)*xi + 2*nu_next - nu
nu_next = nu - h*lambda2*xi, xi in Sgn(z)
c_raw = a/g
```

s 为 rad/s；a/nu 为 rad/s²；g 为 rad/s²/归一化力矩。没有额外 PID、D 项、积分、参考加速度前馈或边界层。
消元后 `z+h*lambda1*sqrt(|z|)*xi+h²*lambda2*xi=s`，分支不依赖旧 nu。
等号归中间分支，其输出 `a=nu-2*s/h`，状态 `nu_next=nu-s/h`。
外分支使用有理化根，推导与完整数值域见 [协议](../ista_redesign/i01/PROTOCOL_CN.md)。

新 API 明确分开只读 `evaluate` 候选与 `commit` 状态推进。提交校验所属对象/轴/代次，重复或陈旧候选拒绝；
同轴成功设参/reset 使旧候选失效，无效操作不改变状态，其他轴及实例互不影响。
`update` 只封装一次 evaluate+commit；没有受保护候选提交接口。
I02 以后必须重新核对冻结/限幅后的输出关系，不能复制原 ISTA 的加性 nu 修正公式。

使用 double 中间量和 float 状态/接口；缩窄前拒绝溢出及非零 subnormal，舍入后检查三隐式方程和 g 映射。
参数/dt 必须为有限正正常 float，但这只是数值有效域；理论要求固定 h、精确 ZOH、单位虚拟通道、
匹配 Lipschitz 扰动且 lambda2>L、lambda1>sqrt(lambda2+L)。没有把这些条件扩展到电机滞后、噪声或变步长。
