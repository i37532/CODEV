接口约定：

- `setParameters(axis, {lambda1, lambda2, g})`：仅设置该轴，成功与失败都不隐式重置 nu；非法配置返回 false，原有效配置保持。调用者必须处理返回值，不能把配置失败视为成功启用。
- `update(axis, rate, rate_sp, dt)`：仅推进所选轴一次，返回 `s/a/c_raw/nu_next/status`；axis 为 0/1/2，对应 R/P/Y。
- `reset(axis, nu=0)`：单轴置为有限初值；非法轴或非有限初值返回 false，状态不变。
- `reset()`：三轴清零，保留参数。`state()` 返回只读的三轴 nu。
- 三轴、不同对象均独立，无全局算法状态。单次调用对**所选轴**原子提交；这不是跨三轴事务，也不是线程安全接口。后续适配器负责生命周期与多轴调度。

### 公式和单位

\[
s_k=\omega_k-\omega_{sp,k},\quad
a_k=-\lambda_1\sqrt{|s_k|}\operatorname{sgn}(s_k)+\nu_k,
\]
\[
c_{raw,k}=a_k/g,\qquad
\nu_{k+1}=\nu_k-h\lambda_2\operatorname{sgn}(s_k).
\]

| 量 | 单位/含义 |
|---|---|
| rate、rate_sp、s | rad/s；误差符号与原 PID 的 rate_sp-rate 相反 |
| a、nu、nu_next | rad/s²，虚拟角加速度通道 |
| lambda1 | (rad/s²)/sqrt(rad/s) |
| lambda2 | rad/s³ |
| dt=h | 秒 |
| g | 每单位归一化力矩指令对应的 rad/s²，必须正值 |
| c_raw | 归一化力矩候选，不限幅，允许超出 [-1,1] |

本步输出严格使用旧 nu；计算、检查整个候选后才执行一次 `_nu[axis]=nu_next`。`sign(0)=0`，因此零误差但 nu 非零时，a=nu 而不是强行输出零。g 只作用于 a→c 映射，不改变内部 nu 的单位/更新。

### 有效域与失败语义

lambda1、lambda2、g、dt 要求为有限正的**正规 float**：从 `numeric_limits<float>::min()` 到 `max()`；明确拒绝零、负值、NaN、Inf 和非正规极小配置。rate、rate_sp 和 reset 初值须有限。配置有效还不代表所有输入组合都能计算成功：逐步检查 s、根号校正项、h×lambda2、a、a/g、nu_next 是否有限。

失败状态区分 InvalidAxis、Unconfigured、InvalidInput、InvalidDt、NumericalError；数值字段保持 NaN，**失败不推进任何 nu**。NaN 是禁止使用该结果的诊断哨兵，不是要发送给执行器的量，更不是“零力矩即可安全”的策略。

数值有效域不等于稳定域：此处未按传感器时间戳判断长停顿，也不夹 dt。极小有限乘积仍可能下溢/舍入为零；没有宣称在 float 全域上保持数学精度。M03 必须再定义实际周期范围、异常中止、生命周期、饱和/nu 上限与参数更新规则。内核没有暗加限幅、边界层、PID D/I、参考加速度前馈或 ISTA 更新。

### 独立 binary64 逐样本校验

`scripts/reference_m02.py` 不导入或调用 C++ 内核，通过 Python 双精度生成交错三轴的 96 步输入、旧/新 nu、a、c。选用二进制可精确表示的输入/增益/步长，使该固定序列的 s、nu 可精确比较；a 和 c 容差为 `2e-6 × max(1,|reference|)`。序列含正负和零误差、不同 g、非零初始 nu。这与手算的旧 nu 定向用例相互补充，但仍只是有限序列。

### 独立对象闭环

使用单独以 double 演化的一阶对象 `dot(rate)=g*c_ZOH+phi(t)`，对恒定保持控制和扰动积分求精确步进；不是拿控制器自身的虚拟预测当作真实对象。另一路 binary64 ESTA 驱动另一独立状态，比较末段误差指标。

- 3 种名义 h：0.001 / 0.004 / 0.01 s；实际 float 值记录在原始日志。
- 3 种合成 g：0.5 / 2.5 / 7，设计增益与对象增益一致。
- 3 种场景：无扰动；恒定 phi=0.4；phi=0.4 sin(0.7t)，第三组同时跟踪 rate_sp=0.15 sin(0.5t)。前两组设定值为零。
- 初始 rate=1 rad/s、nu=0，lambda1=4、lambda2=2。每组约 8 s：分别 8000/2000/801 个采样，共 27 组、97,209 次控制器更新；用实际 float h，最后一组因 ceil 覆盖到略超过 8 s。
- **首次运行前在测试源码中固定**：末约 2 s 的全部采样误差 |rate-rate_sp| < 0.02 rad/s；float 与 double 的末段 RMSE 差 < 0.003 rad/s；不是首次进入阈值就算收敛。
- 实际 **27/27** 通过，全部场景末段最大误差 `0.000418442182 rad/s`，RMSE 最大差 `1.840861e-8 rad/s`。逐场景指标在 `../m02/evidence.json` 和 `run01/StaRateControl.log`。

对象测试是确定性的算法检查，不是统计独立飞行实验；存在 ESTA 非零离散振荡，不宣称精确滑动。没有电机动态、轴耦合、执行器饱和、传感器噪声或 g 失配，更不能把这些合成 g/lambda 当成 Iris 或 DP1000 的标定参数。
