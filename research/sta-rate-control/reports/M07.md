## 2. 接口、公式和单位

复用 ESTA 的 `Parameters`、`Status`、结果基本字段与 `setParameters/update/reset/state` 接口；三轴参数、配置标记和 `nu` 独立。结果另带 `virtual_s`、`xi`、`branch`（1=正分支，2=滑动分支，3=负分支，255=无效）。配置成功不自动清状态；无效配置不改参数/状态；reset 行为由调用者决定。成功 update 仅提交所选轴一次；失败返回错误、NaN 哨兵和 Invalid 分支，所有轴状态保持，**NaN 不是可发送给执行器的安全命令**。

`s=rate-rate_sp`，单位 rad/s；虚拟角加速度 `a` 与 `nu` 单位 rad/s²；`g>0` 单位 rad/s²/归一化力矩；`c_raw=a/g`。lambda1 单位 `(rad/s²)/sqrt(rad/s)`，lambda2 单位 rad/s³。不添加 PID 的 D/I 或参考加速度前馈，不添加边界层/限幅。

令 `alpha=h*lambda1`、`b=-s-h*nu`、`q=h²*lambda2`：

| 条件 | xi | virtual_s | nu_next | a |
|---|---:|---:|---:|---:|
| b < −q | +1 | r² | nu−h·lambda2 | −lambda1·r+nu_next |
| −q ≤ b ≤ q | −b/q | 0 | −s/h | nu_next |
| b > q | −1 | −r² | nu+h·lambda2 | +lambda1·r+nu_next |

外侧两分支使用 `delta=abs(b)-q>0` 和有理化根：

```text
r = 2*delta / (sqrt(alpha² + 4*delta) + alpha)
```

两条等号均归滑动分支。不实时迭代。理想结果应满足：

```text
virtual_s = s + h*a = s + h*g*c_raw
nu_next   = nu - h*lambda2*xi
a         = -lambda1*sqrt(abs(virtual_s))*xi + nu_next
xi ∈ Sgn(virtual_s)，其中 Sgn(0)=[-1,1]
```

特别地，ISTA 在零误差且旧 nu 非零时，可能选择非零 xi 并清除 nu；不能机械套用 ESTA 的 `sign(0)=0` 更新行为。

## 3. 数值有效域及测试覆盖

- 保留 float 输入/状态/结果，局部采用 binary64 中间运算；先检查可表示范围再转换为 float。`s` 使用经检查后的 float 差值，和共享接口一致。各输出独立舍入，方程按浮点误差容限验证，不声称逐位实数等式。
- lambda1/lambda2/g 与 dt 必须为有限、正、normal float。有限 rate/rate_sp 和 reset nu 仍可能因后续运算数值无效而拒绝。非零 subnormal 的 `s` 或结果、溢出的结果都返回 NumericalError，不靠静默归零继续运行；这是刻意收窄的数值有效域，不是全部 float 输入都能求解的承诺。
- `h²*lambda2` 最小仍可在 double 表示；`alpha²+4*delta` 在合法 float 输入下也不溢出 double。测试实际覆盖 float 中 q 下溢的零状态及非零外分支，以及 float 判别式溢出而 double 可安全计算的例子。由外分支 `delta>0` 构造判别式，正常输入不会出现负判别式；不假称注入过不可达的负值。
- 有理化避免 `sqrt(D)-alpha` 消减。测试 `s=nextafter(1,+∞), h=1, lambda1=16, lambda2=1`：直接 float 相减根为 0，而新实现保留非零预测根，另由独立二分参考校验。
- 结果舍入后检查上述三方程和非单位 g 映射：误差不超过每式最大项的 `8*FLT_EPSILON`。例如 `s=2,nu=lambda1=1e30,h=lambda2=g=1` 即使中间量有限，也会因 double 消减导致方程不一致而拒绝，不能仅凭 `isfinite` 判通过。
- 覆盖两条精确二进制边界及各自上下相邻 float、滑动 xi 的 129 个采样、正负对称、零误差/非零 nu、三轴和实例隔离、reset、非法轴/参数/dt/NaN/Inf、s/nu/a/c/virtual_s 溢出及结果下溢，失败时无部分提交。
- 尚未评估板载 double 成本、硬件浮点环境或实时周期预算；这些不能由宿主测试推断。M08 接入前仍须处理公共保护与状态生命周期，M09 再测实际成本。

### 独立对象：理想与受约束结果分开

对象独立执行 `x[k+1]=x[k]+h*(g*c_applied+d)`，**不把 virtual_s 直接赋给对象**。h 为 .001/.01/.1 秒，g 为 .5/1/130.575283，lambda1/lambda2 为 10/6，初始 x=2、nu=0。这些是离线数值参数，不是已标定可飞 ISTA 参数。另独立演化 double 控制器/对象，与真实 C++ float 状态轨迹比较。

| 场景，各 9 组 | 判据与实际结果 |
|---|---|
| 理想无扰动 | 全部在 6 秒预算内达到 abs(x)<1e-7 且 abs(nu)<1e-6；终点最大 abs(x)=3.191755e-9；与独立 double 轨迹最大差 3.459731e-8 |
| 扰动 d=.2 sin(2t) | 运行完整 6 秒；末 .5 秒最大 RMSE=.017803277 < .05；不宣称理想有限步收敛 |
| 测量噪声 .001 sin(17t) | 运行完整 6 秒；末 .5 秒最大 RMSE=.000681325 < .05；噪声与真实对象状态分开 |
| 输出饱和 | 外部限制 abs(g*c_applied)≤2，不修改内核 nu；全部达到上述数值终点，实际对象与理想预测最大差 .839864895，明确不满足理想预测恒等式 |

所有 36 组相对独立 double 轨迹最大差 `2.084373e-6`，小于预设 `2e-4`。理想及饱和对象达到数值终点后停止，不声称机器上精确有限时间归零或无限期保持零；其中 `tail_rmse` 是停止前的片段，可能仍含过渡过程，**不是稳态 RMSE**。受约束试验没有应用公共保护器的 nu 冻结，不能代表 M08 的受保护 ISTA、Gazebo 效果或实机稳定性。
