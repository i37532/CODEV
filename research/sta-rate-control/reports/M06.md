## 2. yaw 独立标定与耦合

实际 Iris/10016/quad_w，world=`sitl/worlds/empty_grey.world`。使用真实 SDF、附属质量合成惯量、生成 mixer、电机 motorConstant/momentConstant、旋转方向和控制输入映射。CCW=+1、CW=−1；电机插件的FLU反扭矩为 `−direction*F*momentConstant`，变换至FRD得到正 yaw 力矩 `sum(direction*F*momentConstant)`。

`F_j=k_j(100+1000*q_j)^2`，`q=mixer*[cR,cP,cY,T]`。在 `T=.707,cR=0,cP=.004,cY=0` 处对实际力矩求导，并解完整FRD惯量方程 `alpha=I^-1*tau`，而非将三轴惯量都当Ixx。

| 量 | 数值 |
|---|---:|
| Izz | .0577115643871 kg·m² |
| gY | 34.5823263568 rad/s²/归一化yaw指令 |
| 保留gR / gP | 130.5752831836 / 112.7635334435 |
| ∂alphaR/∂cY | 19.0391825185 |
| ∂alphaY/∂cR | −.0670505312 |
| 推力.65/.707/.75、yaw±.001/.005/.01扫描的局部gY最大变化 | 7.06649% |

详见 [标定JSON](../m06/calibration.json) 和 `scripts/calibrate_m06.py`。这是模型准静态标定，不是动态飞行辨识；25ms电机滞后和±20%增益测试是工程敏感性范围，不是置信区间。yaw→roll耦合不可忽略，未新增耦合补偿器，而是检查闭环响应和逐轴饱和。

## 3. 控制路径、状态及故障策略

三轴仍独立使用 `s=rate-rate_sp`、旧 `nu[k]` 计算 `a=-lambda1*sqrt(abs(s))*sign(s)+nu[k]`，`c_raw=a/g`，再更新 `nu[k+1]=nu[k]-dt*lambda2*sign(s)`。单位：s为rad/s，a/nu为rad/s²，g为rad/s²/归一化力矩；沿用方向性饱和、nu/指令限制、落地冻结/reset与原子提交。

`StaAxesApplication` 验证 SITL Iris、1/3/7掩码、三轴参数有效性及匹配g；三轴输出全部有效才允许应用。非SITL `_research_iris` 始终false。MODE/AXES及所有未配置实验增益默认值仍为0，不会开机自动切ESTA。

AXES=1/3保持混合路径及未选轴原PID输出。AXES=7的 dispatcher 在调用 PID.update 之前直接跳过；返回的NaN只是内部占位，须被三个有效ESTA结果原子替换，不作为执行器指令。日志新增 pid_updated 和 pid_update_seq，记录实际PID计算，不能把“全轴没有PID比较轴”的空比较当PID等价证明。

继续采用已测试的研究故障策略：latch、禁止本次输出发布、宿主SITL中止，**没有自动PID接管**，不把零力矩称为安全措施。armed期间请求切PID或改轴/增益仅暂存；disarm后状态清零再应用。测试检查完整三轴故障不误用闲置PID，以及切回PID后与新初始化参考的输出一致。
