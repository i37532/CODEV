# M04 Iris roll 输入增益与预设边界

冻结于首次 ESTA 飞行之前（2026-09-14），前置 HEAD 为 4f4df5fe09ccc1c52de7149b1526a4b7931baa4f。机器可读原始模型结果、资产指纹与工作点扫描见 calibration.json；试验门槛和窗口定义见 protocol.json。这是模型专用静态标定，不是 DP1000 标定或飞行动态辨识。

## 映射推导

实际 Iris SDF、GPS include 和各 link 平行轴合成后，总质量 1.55 kg，质心 roll 惯量 Ixx=0.03004334348 kg·m²。只取 base_link 的 0.029125 会遗漏附属质量。完整张量及质心存入 JSON；这里忽略很小的 Ixz 耦合，未把电机旋转动态等效为静态刚体。

生成后的 quad_w 混控 roll 系数按电机 0～3 为 [-0.495383,+0.495383,+0.495383,-0.495383]，实际 SDF 横向力臂（FLU）[-0.22,+0.20,+0.22,-0.20] m。实际 SDF 和 mixer 几何不完全相同，计算用二者各自的值，未改模型使其一致。

无饱和、THR_MDL_FAC=0 的局部工作点：q_j=r_j*c_R+p_j*c_P+y_j*c_Y+T；mixer 从 q 转为 [-1,1]，PWMSim 1000～2000 输出经 simulator 还原为 q。Gazebo 指令 omega_j=100+1000*q_j，稳态推力 F_j=5.84e-6*omega_j² N。

roll x 轴在 FLU/FRD 中同向，故 tau_R=sum(y_j*F_j)，g_R=(d tau_R/d c_R)/Ixx，正 roll 指令应产生正 roll 角加速度。标定工作点 T=0.707、c_P=0.004、c_Y=0，来自 M00 近悬停输出范围，得到 g_R=130.575283 rad/s²/单位归一化 roll 指令。ESTA 输出映射 c_R=a_R/g_R；不能直接令 g=1。

在 T=0.65/0.707/0.75、c_R=±0.001/±0.005/±0.01 逐点核对增量方向及增益，扫描最大相对中心变化 7.062%。中心点正负有限差分一致；这只是该局部静态模型的误差/变化，不是与真实飞行测量对比的置信区间。电机 12.5/25 ms 延迟、滤波、速度相关推力损失、阻力、机体耦合和测量噪声仍在实际仿真中。离线采用 ±20% 增益及 25 ms 电机延迟作工程敏感性检查，不宣称该范围经过统计估计。

## 冻结场景与开发门槛

所有飞行沿用原 Iris 启动器/灰色 world、原 PID/姿态/位置参数和电机模型。保持 AUTO_LOITER 60 s，开始 15 s 后触发一组正负对称 roll 角速度正弦脉冲：幅值 0.04/0.08/0.12 rad/s，每个一周期 4 s，起点相隔 8 s，各周期积分为零。原 mc_att_control 在其原 rates setpoint 发布位置叠加脉冲，不新增第二个发布者；姿态环持续修正姿态误差，pitch/yaw 和推力仍来自原姿态/位置外环。该激励不是开环恒定 roll rate，也不是外加物理力矩。

纯 PID 和 ESTA 采用完全同一脉冲脚本，各重新启动 3 次。三次运行不当作独立随机种子样本。60 s 全窗口和脉冲起点至 +24 s 跟踪窗口分别计算高频 roll RMSE；每个 ESTA 重复均要求不超过同窗口三个 PID 重复中位数的 1.25 倍。其他轴继续逐位核对原 PID 输出并报告 RMSE。

预设边界：倾角≤15°、悬停估计高度跟踪误差≤1 m、角速度各轴≤1 rad/s、归一化 roll 命令≤0.15、|nu_R|≤3 rad/s²；不得 NaN、故障/回退/中止或 failsafe，必须完成降落自动上锁。脚本边界检查有通信/调度延迟，离线还须逐样本核对；只限 SITL，不是实机保护承诺。若超过预设门槛，保留该次失败，不在看到 ESTA 结果后放宽限值。

开发初值 lambda1=3、lambda2=6，g_R 固定为上述模型值；参数单独存放于 iris_esta_roll.json，不改 airframe 默认。若需要调参，另存每个候选及失败数据，最终对照必须冻结同一版本和参数。原 PID 的 FF=0 保留；不向 ESTA 添加 PID D、重复积分或参考加速度前馈。

## 初始来源和复算

运行 python3 research/sta-rate-control/scripts/calibrate_m04.py --output <新的 JSON 路径>。依赖已有实验 Python/numpy。脚本读取实际生成的 mixer 表，若未构建须先构建 PID 固件；不要覆写 calibration.json 冒充旧结果。输入模型/插件文件的 SHA-256 已记录，后续运行需核实未变化。固件仅在 PX4 SITL 构建、SYS_AUTOSTART=10016、AXES=1、g_R 匹配该模型值并且所有选中参数有效时接受 ESTA。此门禁不能检测人为替换 SDF，故脚本/报告的模型指纹核对仍不可省略。
